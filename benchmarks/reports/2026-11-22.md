# Manual report, 2026-11-22

One run on a shared KVM guest. Not a public leaderboard submission. Rate limiting was off. `SO_REUSEPORT` was off; workers share one listen fd. Echo sends `Connection: close`, so every HTTP request is a new TCP connection.

The run started at 12:38 (Asia/Shanghai).

Machine: Intel Xeon (family 6, model 207), 4 vCPU, 15.6 GiB RAM, KVM
OS: Ubuntu 24.04.5 LTS, Linux 6.12.113+
PHP: 8.3.36

## Listen model

Keep the shared listen fd. This report records P99, including 18.41 ms at 63637 QPS with four Echo workers. It does not compare `SO_REUSEPORT` on and off, and this guest is not a quiet benchmark machine. Do not change the listen model from these numbers.
